This game started from a blank page: there is no game yet, only the studio
library and a placeholder to replace. Rewrite this file as the game takes
shape — it is the file map.

What is here now:

- index.html — the placeholder: a title, one line of text, and the script
  tags for all seven libraries, so a first script can call any of them
  without touching it. Replace the rest with the game's own page.
- config/controls.js — the game's controls, seeded by the input library.
  Its `SCHEME` was chosen when the game was made.
- config/achievements.js — an empty list. Fill it in once the game says
  moments worth earning something for.
- config/play.js, config/look.js, config/words.js — not here yet. The first
  thing built makes them.
